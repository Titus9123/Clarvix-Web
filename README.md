# קלארוויקס ווב

אתר סטטי בעברית עבור Clarvix Core — שירות מנוהל לעסקים קטנים שמתחיל בתצוגה אישית, ממשיך לאתר פעולה ומוסיף Smart Request לוואטסאפ.

## תכונות

- ממשק מלא מימין לשמאל
- התאמה למחשב, לטאבלט ולמובייל
- נגישות בסיסית ותמיכה בהפחתת תנועה
- ללא תלויות בנייה
- הצעת Core אחידה במסלול חודשי או שנתי
- טופס התאמה לתצוגה מקדימה חינמית

## הפעלה מקומית

פתחו את `index.html` בדפדפן או הפעילו שרת קבצים סטטי בתיקייה.
