# קלארוויקס ווב

אתר סטטי בעברית עבור Clarvix Core — שירות מנוהל לעסקים קטנים שמתחיל בתצוגה אישית, ממשיך לאתר פעולה ומוסיף Smart Request לוואטסאפ.

## תכונות

- ממשק מלא מימין לשמאל
- התאמה למחשב, לטאבלט ולמובייל
- נגישות בסיסית ותמיכה בהפחתת תנועה
- ללא תלויות בנייה
- הצעת Core אחידה: חבילת שנה ראשונה בתשלומים או תשלום שנתי מראש
- טופס התאמה לתצוגה מקדימה חינמית
- דפי פרטיות, נגישות וביטול נפרדים ובחירת מדידה אופציונלית

## תפעול

תיקיית `operations/` כוללת CRM, onboarding, רישום דומיינים, יומן הסכמות, QA, ספקים וטיוטת הסכם B2B. אלה מסמכים פנימיים ואינם מפורסמים באתר.

## הפעלה מקומית

פתחו את `index.html` בדפדפן או הפעילו שרת קבצים סטטי בתיקייה.
