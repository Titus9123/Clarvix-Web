# Onboarding Clarvix Core

## Identidad y contrato

- [ ] Nombre legal, nombre comercial y número de עוסק/empresa verificados.
- [ ] Confirmación escrita de que la compra es para fines empresariales.
- [ ] Contacto único autorizado para aprobar contenido.
- [ ] Propuesta y contrato firmados; coste total, asignación construcción/servicio, hitos, salida proporcional e IVA claramente indicados.
- [ ] Antes del pago, חשבון עסקה/solicitud de pago si hace falta; después de cada cobro, קבלה en iCount. No emitir חשבונית מס mientras Clarvix sea עוסק פטור.
- [ ] La propuesta/contrato privado incluye nombre jurídico, número de עוסק y domicilio fiscal verificados; esos datos no se copian al repositorio público.
- [ ] Confidencialidad incluida; decisión opcional de no exhibición pública (+500 ₪) registrada por separado.

## Alcance ABD

- [ ] Acción principal y alternativa aprobadas.
- [ ] Máximo siete bloques de contenido.
- [ ] Smart Request: máximo seis preguntas, dos ramas y un destino.
- [ ] Confirmado que no se solicitan datos médicos, financieros, de menores, identidad u otros datos sensibles.
- [ ] Confirmadas dos rondas consolidadas antes de lanzamiento y cero cambios mensuales incluidos.

## Dominio

- [ ] Nombre disponible y aprobado.
- [ ] Autorización para registrar y administrar recibida.
- [ ] Cliente cargado como Holder legal; Clarvix como pagador/contacto técnico cuando proceda.
- [ ] Correo del Holder independiente del dominio y con 2FA.
- [ ] Registro anotado en `domain-register.csv` y recordatorios 60/30/7 días.

## Contenido y derechos

- [ ] Textos, teléfono, email, precios y horarios aprobados.
- [ ] Cliente confirma derechos sobre logotipo, fotografías y testimonios.
- [ ] Consentimiento de portfolio registrado o suplemento privado contratado.
- [ ] Avisos legales personalizados con identidad y contacto del cliente.
